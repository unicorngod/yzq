# 小孩培养细节计划

## 目标

培养普通小孩，能上深圳当地重点高中，并进入国内 211/985 重点大学。  
本项目主要关注**学习方面**；二年级阶段重**习惯与闭环**，不追超前、不堆课。

## 基础情况

1. 小孩 2026 年 9 月升小学二年级，在读宝安区西乡街道流塘小学。
2. 家庭四口，有刚出生的弟弟。
3. 父母均本科毕业，上班忙，希望培养**自己学习的习惯**。
4. **一年级综合评估：**  
   - **一上：** 数学 A｜语文 A｜英语 **A+**｜科学 A｜美术 **A+**｜音乐 A｜体育 A｜劳动 **A+**  
   - **一下：** 数学 **A+**｜语文 A｜英语 A｜科学 **A+**｜道法 A｜劳动素养 A｜体质素养 A｜音乐 A｜美术 A；课堂倾听 A｜表达 **B**｜记录 A  
   - 数学平时测验常 B/B+，一下期末冲高（详见 [`孩子学习画像.md`](孩子学习画像.md) §〇）。

## 二上家长共识（目标对齐 · 2026-08-23 定）

> 依据：[`日志-2026-08-暑假.md`](日志-2026-08-暑假.md) 暑假复盘（2.4 / 3.4 / 4.4）及 8.21–8.22 日志。

### 8 月结论（一句话）

**不必整体加量加紧，要「结构化收紧」——少而硬、闭环要严。**  
一年级主科全程 A 档（一下数学/科学 A+）；暑假三科过程约 3～4 分——**家底不差，短板是日常自启不稳、数学平时发挥不稳**；8.22 证明能力在，瓶颈在任务设计与启动。

### 加紧原则

| 不做（暑假已验证无效） | 要做（对准长远目标） |
|------------------------|----------------------|
| 再加练习册 / 网课 / 语法课 | 三科各 **1 条主线闭环** |
| 每天语数英全满、追暑假债 | **固定启动块** 25～35 分钟（点心后） |
| 靠长时间陪写、催半天 | 写话走 **口述→整理→誊写** |
| 恢复「每天一页拼音」硬指标 | 错字本 / 错题本 / 词句本 **每周销号** |

### 每周最小包（二上硬底线）

| 科目 | 非 negotiable |
|------|----------------|
| 语文 | 错字本听写/销号 ≥1 次；阅读 ≥5 天×15 分钟（**可含每周 1 则成语故事亲子读**）；写话 1 篇（口述后写）；读完记阅读记录本 1 行 |
| 数学 | 限时计算（减量）；错题本；应用题 **每周 1～2 题**（《学而思秘籍·应用题专项突破》+ 思维闯关，画图讲清） |
| 英语 | 校内第一；词句本 **≥2 次/周**；跟读 ≥4 天；台账见 [`英语词句积累学习方法.md`](英语词句积累学习方法.md) |

详细执行表见暑假日志 **2.4 / 3.4 / 4.4**；错字方法与台账见 [`语文错字积累与台账.md`](语文错字积累与台账.md)；英语词句方法与台账见 [`英语词句积累学习方法.md`](英语词句积累学习方法.md)；阅读记录本见 [`阅读记录本使用方法.md`](阅读记录本使用方法.md)；逐周对照见 [`二上逐周计划表.md`](二上逐周计划表.md)。

### 启动规则

1. 放学：**点心 15 分钟 → 学习块 25～35 分钟**（先校内作业，加练只选 1～2 项）。  
2. 语文写话、古诗：**每周 1～2 个重点块**；**秘籍每周 1 节**（1→2→3 级，先 2 级再 3 级），不每天摊大饼。  
3. 家长少问「学了多少」，多问「今天最小包哪一项完成了」。

### 与长远目标怎么对齐

| 阶段 | 重点 |
|------|------|
| 二上～三上 | 固定时段、能独立启动、错了会订正 |
| 阅读 | 注音/漫画 → 桥梁书，为三四年级阅读量打底 |
| 语文输出 | 错字本闭环 + 口述后写，避免「课上会、笔头不会」 |
| 数学 | 保持计算耐力，补应用题理解 |
| 英语 | 词句过关；**兴趣歌看词跟唱**可作加餐（8.23 验证）；少追课数 |

**合格线：** 二上若「每周最小包」稳定做到 **≥70% 周数**，对深中/985 路径是合格起步；若仍像暑假加练那样只有 20%～50%，优先**减量收紧**，不加量。

### 常见疑问（双减 / 落后焦虑）

> 详细问答见 [`疑问与解答.md`](疑问与解答.md)。  
> **双减：** 家里闭环巩固对，勿做成隐形全日制。  
> **焦虑落后：** 按评估不落后；短板是「稳」与自启——少而硬，不加册。
