# 小晴 · 测验成绩与错题台账

> **用途：** 持续记录**每一次**校内/家庭测验成绩，以及错题类型与订正情况——把「平时 B、期末 A+」这类规律看清楚。  
> **原则：** 物理错题本给孩子订正；**本文档给家长做台账与复盘**（仿 [`英语词句积累学习方法.md`](英语词句积累学习方法.md) 双轨）。  
> **关联：** [`孩子学习画像.md`](孩子学习画像.md)｜[`概述.md`](概述.md)｜[`每日学习日志.md`](每日学习日志.md)｜当月日志（只写一句话即可）

**文档版本：** 2026-08-26 建｜模板空表，二上起填。

## 一、放在哪？为什么新开文件

| 文档 | 适合记什么 | 不适合 |
|------|------------|--------|
| **本文档（推荐）** | 历次测验分数/等级、错几题、错因归类、是否订正回看 | 每天流水账 |
| 当月每日日志 | 「今天单元测数学 B+，错 3 已订正」**一行** | 详细错题清单（会撑爆月文件） |
| [`孩子学习画像.md`](孩子学习画像.md) | 学期末总评、规律结论 | 每次测验明细 |
| 物理数学错题本 / 语文错字本 | 孩子订正、重做 | 跨学期趋势统计 |
| [`语文错字积累与台账.md`](语文错字积累与台账.md) | 错字明细、销号、写字表对照 | 每次听写明细 |

**结论：新开本文件。** 每日日志只打钩式带过；画像学期末根据本台账改一版即可。

## 二、怎么记（尽量轻）

### 家长最快上手

1. **测完当天或当晚**填 §四「测验登记」一行（2～5 分钟）。  
2. 错题：物理本订正；本文档只写**错因类型 + 题号/简述**（不必抄整题）。  
3. **每周或单元结束后**扫一眼 §五「错因统计」是否要加计数。  
4. **学期末**填 §六，并把一句话结论抄进画像 §〇 或概述。

### 记什么 / 不记什么

| ✅ 要记 | ❌ 不必记 |
|---------|-----------|
| 日期、科目、测验名、满分/得分或等级 | 每道对题的过程 |
| 错几题、主要错因（选标签） | 整卷拍照全文进 md（可另存相册） |
| 是否订正、是否隔日重做对 | 班级排名（没有就不猜） |
| 感觉（细心/粗心/不会/紧张） | 每次写长分析 |

### 错因标签（统一用，便于统计）

| 标签 | 含义 | 常见科目 |
|------|------|----------|
| `抄错` | 看错数、抄错题 | 数学 |
| `进退位` | 进位/退位漏或错 | 数学 |
| `运算顺序` | 括号、漏算半截 | 数学 |
| `概念` | 不会 / 公式用错 | 数语英 |
| `读题` | 没看清题意 | 数学应用、语文 |
| `字形` | 错字、形近 | 语文 |
| `拼音` | 声母韵母混淆 | 语文 |
| `词句` | 单词/句子不会 | 英语 |
| `粗心未查` | 会做但未检查 | 各科 |
| `其他` | 自写一句 | — |

## 三、等级对照（可选）

学校若用等级制，家长可自行对应（仅供趋势，非官方换算）：

| 等级 | 大致含义（自用） |
|------|------------------|
| A+ | 优秀冲高 |
| A | 良好稳定 |
| B+ / B | 中等；需看错因 |
| C 及以下 | 当周必订正 + 同类再练 |

**二上关注点（来自画像）：** 数学不只看期末，更要看**单元测/平时测是否从 B 往 A 靠**。

## 七、与物理本、每日日志怎么分工

```
测验当天

周末/单元末
  → §五 错因点一下数
学期末
  → §六 复盘 → 更新 [`孩子学习画像.md`](孩子学习画像.md) §〇
```
