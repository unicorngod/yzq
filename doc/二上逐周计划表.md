## 使用说明（家长先看）

### 暑假复盘 → 本表怎么读

8 月结论：**家底不差（三科约 3～4 分），短板是自启不稳**；不必整体加量，要把 **错字本 / 错题本 / 词句本** 三条闭环跑顺。

| 科目 | 二上抓手（每周围绕这个，不另开线） | 复盘章节 |
|------|-----------------------------------|----------|
| 语文 | 错字本销号；写话 **口述→概括→誊写**（说长写短）；阅读 ≥5 天 | 2.4 |
| 数学 | **限时**计算（减量）；错题本；应用题 **每周 1～2 题**（《学而思秘籍·应用题专项突破》+ 思维闯关 · 画图讲理） | 3.4 |
| 英语 | 校内平板第一；**词句本** ≥2 次/周；跟读 ≥4 天；牛津树重质量 | 4.4 + 词句文档 |

**启动：** 点心 15 分钟 → 学习块 **25～35 分钟**（先校内作业，加练只选 1～2 项）。语文写话、古诗：**每周 1～2 个重点块**；**秘籍固定每周 1 节**（1 级收尾 → 2 级 → 3 级，不跳级）。

### 每周固定节奏

| 时段 | 做什么 | 约多久 |
|------|--------|--------|
| 工作日作业后 | 语文三选一（读/听写/字词）+ 数学口算或 1～2 题 | 25～35 分钟 |
| 工作日睡前 | 阅读 | 15～20 分钟 |
| 周六上午 | 英语：校内/跟读 + **词句本** + 牛津树或拼读；数学错题重做 | 40～50 分钟 |
| 周六或周日 | 阅读复述 + 数学思维 2～3 题（可选） | 40 分钟 |
| 周日晚上 | **本周自测**（见每周末「过关标准」） | 20 分钟 |

### 跨周固定加练（各周任务之外的「最小包」）

> 下面每项 **每周围绕一次**；与当周教材任务 **叠加但不取代**。忙带弟弟时见 **附录 A**。

| 科目 | 每周必做 | 说明 |
|------|----------|------|
| 语文 | 错字本听写/销号 **≥1 次** | 23 字存量继续销；课内听写错字并进本 |
| 语文 | 写话/日记 **1 篇** | **口述可长 → 家长帮概括 → 誊写要精**；生字可拼音 |
| 语文 | 阅读 **≥5 天 ×15 分钟** | 有拼音/桥梁为主；**每周可含 1 次成语故事亲子读**（家里带拼音书）；337 或古诗小块按需 |
| 语文 | 学而思秘籍 **每周 1 节** | **1 级收尾 → 2 级（一下）→ 3 级（二上）**；不跳级；兴趣补充 |
| 数学 | 限时计算 + 错题本 | **黄冈/学而思计算轮换**，不两本每天满页 |
| 数学 | 应用题 **1～2 题** | 《学而思秘籍·应用题专项突破》+ **思维闯关**；画图 + 口述「先求什么、再求什么」；校内有同类错题可另计，**总量约 2～3 道/周、不叠题海** |
| 英语 | 校内平板/作业 **跟紧** | 暑假 20/20 证明执行力在，仍第一优先 |
| 英语 | 词句本 **≥2 次/周** | 9 月前 3 周认读进本；9 月第 4 周起含小听写；见下方节奏 |
| 英语 | 跟读 **≥4 天** | 课文音频、牛津树、或主题歌跟唱 |
| 英语 | 牛津树 L2 **2～3 节/周** | 每节：跟读 + 说 2～3 句 + **圈 3 词进词句本** |

### 英语听写节奏（二上）

- **9 月第 1～3 周**：只认读、进本，不硬听写整单元。  
- **9 月第 4 周起**：每周 2 次，每次 5 词，从本里已认读过的词抽。  
- **周六英语块**末尾留 5～10 分钟给词句本/听写；与描红错开。
