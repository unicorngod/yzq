# 小晴每日学习日志（索引）

> 用途：按月查看、填写、总结；每天记录写在对应月份文件里。  
> 关联计划：[`二上逐周计划表.md`](二上逐周计划表.md)｜[`2-3年级学习计划.md`](2-3年级学习计划.md)  
> 目标与家长共识：[`概述.md`](概述.md)  
> 家里教材/书/课登记：[`课外资源清单.md`](课外资源清单.md)

---

## 怎么用

1. 打开当月文件，每天睡前填 2～5 分钟。  
2. 周末在当月文件里写「本周小结」。  
3. **月末**在当月文件填「本月收获总结」，并把一句话抄到下方「月度收获一览」。  
4. 需要新月份空表时，说「生成 X 月日志」即可。

### 填写示例

```
### 2026-08-21（五）
- 对应计划周：第 0 周（开学前）
- 语文：听写一年级字 30 个，错 3 个已订正
- 数学：100 以内加减摸底 20 题，对 17 题
- 英语：字母 A–M 认读复习
- 阅读：《猜猜我有多爱你》，亲子共读
- 习惯/其他：独立写完暑假作业 1 页
- 今日状态：😊 专注 / 一般 / 疲惫
- 明日重点：字母 N–Z；错字再听写
```
