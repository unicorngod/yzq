#### 课堂过程（一下评估）

| 维度 | 等级 | 备注 |
|------|------|------|
| 课堂倾听 | **A** | 听得进 |
| 课堂表达 | **B** | 课上开口相对弱（对比：家里口述写话很敢说） |

**一上→一下变化（简读）：**

| 方向 | 科目 |
|------|------|
| **升档** | 数学 A→A+；科学 A→A+ |
| **降档** | 英语 A+→A；美术 A+→A；劳动 A+→A（一下记为劳动素养） |
| **持平** | 语文 A；音乐 A；体育/体质 A |

**怎么读（对画像的含义）：**

1. **一年级全程主科在 A 档及以上** → 校内属于**中上～偏上**，印证「家底够用、不是落后要狂补」。  
2. **数学「一上 A → 一下 A+」，但平时常 B/B+** → 上限在抬、过程不稳；与暑假「会算常错」一致；二上抓过程正确率，不因期末 A+ 加超前。  
3. **英语一上 A+、一下 A** → 曾有冲高；暑假词句留存弱是过程短板，词句本要把「期末档」稳住。  
4. **倾听 A + 记录 A、表达 B**（一下）→ 输入与笔头强，课上开口偏弱；家里口述丰富 ≠ 课上主动发言。  
5. 音体美劳整体 A 档：素质课不拖后腿；不必单开艺术焦虑线。

## 一、一句话画像

**能力中上、家底够用（一年级主科全程 A 档；一下数学·科学 A+，一上英语·美术·劳动曾 A+；倾听·记录 A，课上表达 B）；执行上「任务清楚就肯做、开放收尾就拖延」；兴趣一来能自驱，空催半天没用；数学尤甚——期末能爆发，平时易粗心掉档；家里敢口述，课上开口偏弱。**  
二上不靠加量超前，靠**固定启动块 + 三条闭环 + 扬长（耐力计算、视听跟读、家口述）+ 把平时稳定度往期末靠 + 轻量练课上说一句**。

## 二、学习者类型（跨学科）

| 类型标签 | 证据 | 对家长的含义 |
|----------|------|----------------|
| **任务型 / 可见终点型** | 描红 38 页全勤；数学日更计算两本；拼音「有整页任务」能做满，暑假「一天两三行」就偷工 | 布置要**具体、短、可打勾**；少说「把作业弄好」 |
| **脚手架型** | 圆片平均分：讲题画图后能自己做对；应用题理解弱；日记需家长帮概括 | 默认路径：**带做 → 半独立 → 检查**，不指望一次独立读懂 |
| **兴趣自驱型** | 《极地列车》后主动听歌；秘籍愿看；想看《尼尔斯》；**9.1 脱词清唱第一段** | 给情节/歌曲切口；开口进步用歌巩固 |
| **视听跟读型** | 牛津树、平板、描红、看词跟唱 | 英语少死背表，多用「看+听+跟」 |
| **口述强于誊写** | 家里口述三四百～六七百字；誊写易拖 | 写话固定：**口述 → 概括 → 誊写** |
| **课上表达偏弱** | 课堂表达 **B**；倾听/记录均为 **A** | 敢说在家、课上需练「举手一句」；别误判为「不会说」 |
| **粗心 ≠ 不会** | 数独全对；计算常错 1–3；**一下平时测验常 B/B+、期末数学 A+** | 评「细心/全对」，少评「快/做完」；相信天花板，抓过程稳定 |

**对照：** 不是「懒」或「差」——同一孩子，规则清晰的任务（数独、一页计算、描红）表现明显好于开放任务（日记收尾、成语每天、无终点加练）。

## 三、长处（要保护、要放大）

### 1. 计算耐力与订正习惯（数学最大资产）

- 暑假几乎日更计算；黄冈 24 页 + 学而思计算至约 24 页；肯订正；8.25 整页 22 题可只错 1。
- **一下期末数学 A+**（平时测验常 B/B+）→ 能力够得着顶尖档，日常稳定性是缺口。
- **发挥：** 二上保留**短时限时计算**仪式感，减量不减习惯；错题本写「错因一句话」；目标是**把平时从 B 拉向 A**，不是再加超前难度；评价口令从「做完了吗」改为「全对了吗 / 错因讲清了吗」。

### 2. 书写通道清楚

- 描红全勤、写字班在续、字母默写从常错到能完成。
- **发挥：** 写字班继续作主渠道；英语描红减量即可，不另堆字帖。

### 3. 古诗与识字有底子

- 古诗约 60 + 假期复习 11；《四五快读》第 4 本基本认完；错字本已建（约 23 字）。
- **发挥：** 古诗小块复习（不追 75 清零）；错字本销号当语文主抓手。

### 4. 愿读、愿跟读（阅读/英语入口）

- 米吴漫画、337 晨读、牛津树 L2 约 33 课、校内英语平板 20/20。
- **发挥：** 阅读合法化注音/漫画/桥梁；英语校内平板第一；牛津树「跟读 + 圈词」。

### 5. 兴趣联结一旦点燃，投入极深

- 电影→主题歌→看词跟唱→8 词较清；秘籍愿看。
- **发挥：** 英语每月 1～2 次歌餐进词句本；秘籍每周 1 节（1→2→3 级）；**不**靠兴趣堆第四条主课。

### 6. 口述表达丰富（家里）+ 倾听/记录好（课上）

- 家里能讲长、有画面感；家长略整理即可成文。
- 课上：**倾听 A、记录 A** → 输入与笔头记录是强项。
- **发挥：** 写话默认口述后写；保护自发小本；要求「说可以长、写要精、一次写完」。课上用倾听优势消化内容，表达另练「举手一句」。

### 7. 结构化任务里的空间/逻辑

- 数独全对；长度测量较好；图形叠加是培优自信区。
- **发挥：** 数独作调剂；培优图形可作兴趣加餐；应用题用「画图」接上优势区。

## 四、短处（要改方法，不加量硬撞）

| 短板 | 表现 | 根因判断 | 改善抓手（二上） |
|------|------|----------|------------------|
| **日常自启不稳** | 8.21 催半天；晚间补；**9.2 21:30 开下半截→23:15**；**9.3 22:31**；**9.4 周五玩、叫回困难、学习少** | 缺固定时段 + 开放任务无终点；社交/亲子玩易拖 | **点心后立刻开作业**；周五玩先约定时限；爆量日课外可为零 |
| **课内必写字不稳** | **北 9.4 销号**；广/宽连对待再听销；**9.4** 海/办新错；迎/欢待练 | 存量大、需分批销；回归有效 | 词中听写；**连对 3 次销号**；待过关 ≤25 |
| **计算粗心 / 发挥不稳** | 加看成减；进位/个位；十位算错；**9.5** 8 题**全对**且**口念加减过程**≈3 分钟 | 题多+分心；口念可能有效 | **限时短页**；禁边听；**口念过程**可续试；格式样板 |
| **课堂表达偏弱** | 评估 **B**（倾听/记录均为 A） | 公开场合开口少，非不会说 | 每周目标：课上主动说 **1 句**完整话；家练「30 秒说清一件事」 |
| **应用题 / 语言转数学** | 试课卡理解；圆片需带讲；**8.28 知给求差能订正不能讲解** | 读题、抓数量关系弱；视频自学质量一般 | 秘籍专项 **每周 1～2 题**：画图 + **能讲解** |
| **写话易说太长、誊写易拖** | 口述六七百字；**9.5** 日记约120字仍由家长总结起草 | 不会自行概括；启动难 | **下一步：她试起草→家长改→再誊**；短篇一次写完 |
| **拼音声母韵母易混** | **9.2–9.3** 声母韵母爆；**9.4** 升→shen；**海调号**（读变调写原调不会） | 对比练不够；调号规则新坑 | **拼音错题本**分流；小卡含**调号规则** |
| **英语词句留存弱** | 课多、记住少；校内词弱 | 缺窄词表复习闭环 | 词句本 ≥2 次/周；看词跟唱须圈词 |
| **独立读无拼音书抗拒** | 暑假推荐书未读；**9.4《尼尔斯》拼音版到货并开读**；杂志注音可用 | 台阶过高时抗拒；有兴趣/注音切口可接 | 注音杂志/漫画合法；兴趣自驱优先 |
| **家长加练易注水** | 语文加练约 20%；英语后期松 | 任务太大、并行太多 | 每周最小包；秘籍/歌餐限频 |

## 五、同龄竞争力（务实估计）

> 结合**一下期末综合评估** + 暑假过程表现；用于定策略，不当焦虑依据。  
> 若仍觉得「落后」：先读 [`疑问与解答.md`](疑问与解答.md) §二。

| 维度 | 大致位置 | 说明 |
|------|----------|------|
| **校内综合评估（一年级）** | **中上～偏上** | 一上～一下主科均 A 档；一下数学/科学 A+；一上英语/美术/劳动 A+；**倾听/记录 A，表达 B** |
| **课上过程能力** | 听记强、开口中等 | 输入与记录好；公开表达是短板，可轻量练 |
| **校内跟课 / 作业执行** | 中上 | 平板全勤、计算日更强；自启仍弱于「不用催」的孩子 |
| **语文** | 中上 | 期末 A；识字古诗有底；写话稳定性一般 |
| **数学计算（能力）** | **偏上** | 期末 A+ 证明上限；平时 B/B+ 说明未稳在上限 |
| **数学计算（日常稳定）** | 中等～中上 | 二上主攻「过程正确率」，把平时贴近期末 |
| **数学应用 / 思维** | 中等略偏弱 | 需脚手架；培优刚开头 |
| **英语** | 中上 | 期末 A；词句内化仍是过程短板 |
| **学习习惯（自启+闭环）** | 中等偏下～中 | 相对尖子家庭差距最大处；性价比最高抓手 |
| **综合（对深中/985 路径）** | **合格起步偏上** | 期末单证已够「不落后」；真正差距在习惯与稳定发挥 |

**结论：**  
- 期末成绩说明：**不是落后生**；数学尤其有冲高潜力。  
- 「平时 B、期末 A+」提醒：二上盯**单元测/限时正确率**，比再买超前教材更重要。  
- 同学里仍靠**自启 + 三本销号**拉开长期差距，不靠多一门课。

### 改善弱点（方法，不是加册）

| 弱点 | 怎么改 | 明确不做 |
|------|--------|----------|
| 自启 | 点心后固定块；任务写在可见清单 | 不靠催半天、不每天语数英全满 |
| 粗心 / 发挥不稳 | 错题本 + 全对表扬细心；单元测当小期末 | 不因期末 A+ 加超前；不恢复双本大页 |
| **课上表达 B** | 每周目标课上主动 **1 句**；家练 30 秒说清一件事 | 不开演讲班、不批评「怎么不举手」 |
| 应用题 | 家长带「读题→画图→列式→讲一句」；主材《学而思秘籍·应用题专项突破》+ 思维闯关，**每周 1～2 题**；培优视频后须抽查**能讲解** | 不另报一对一（已试课结论）；不叠题海 |
| 写话拖 | 当日收口；说长写短 | 不跨日敞口长文 |
| 拼音易混 | 错字本对比 3～5 组 | 不恢复每天一页拼音 |
| 英语词空 | 词句本销号；看词必须圈词 | 不叠 HE 体系课+语法+多牛津 |
| 无拼音书 | 注音/桥梁过渡 | 不强迫暑假推荐书债 |

## 七、二上「人设」提醒（给父母）

1. **她是「规定清楚就做得好」的孩子**——你的工作是设计任务，不是加课时。  
2. **兴趣是燃料，闭环是方向盘**——歌与秘籍可以有；词句本/错字本/错题本必须有销号。  
3. **和同龄比习惯，不比超前册数**——深中/985 路径在二年级看的是能否独立启动与订正。  
4. **新生儿期允许「最小包」**——70% 周达标即合格；崩了先减量，再谈加码。  
5. **家里敢说 ≠ 课上敢说**——倾听/记录已是 A；表达从「每周举手一句」轻量练即可。  
6. **远景可种、日常不加压**——校园晚会、大学校园可留「好羡慕」；「考上很难」点到为止；日常仍盯细心/订正/启动（与愿望卡 A+ 同理）。
