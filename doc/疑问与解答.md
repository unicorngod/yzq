## 一、双减下一二年级不留书面作业，家里这样练对吗？

**提问背景（2026-08-28）：**  
政策规定一二年级一般不留书面作业等；家里有错字本、词句本、计算/应用题、培优视频等，担心是否违背双减。

### 结论

**方向大体是对的。** 与双减「减负不减质」不矛盾；要警惕的是**量又堆回去**，不是「家里完全不能练」。

### 双减对一二年级实际在说什么

| 政策侧重点 | 含义 |
|------------|------|
| 校内一二年级一般不留**书面作业** | 减轻学校书面负担，不是禁止家长一切辅导 |
| 压校外学科培训 | 少报班、少抢跑、少机构题海 |
| 保证睡眠、运动、亲子时间 | 学习不能挤掉健康与生活 |

政策管的是**学校作业与培训乱象**；家庭里巩固会写字、会算、会认词，仍是正常责任，只是要**少而准**，不是另开第二套学校。

### 对照我们现在的做法

| 我们在做的 | 和双减是否合拍 |
|------------|----------------|
| 三本闭环（错字本 / 错题本 / 词句本），销号再移出 | ✅ 对症，不是盲目加量 |
| 每周最小包、点心后 25～35 分钟 | ✅ 有边界，符合低年级精力 |
| 不恢复「每天一页拼音」、计算双本减量 | ✅ 主动减负 |
| 秘籍/牛津树/培优有上限（每周 1 节、不跳级） | ✅ 兴趣加餐，不当主粮 |
| 应用题每周 1～2 题精做，强调画图讲解 | ✅ 质量优先 |
| 假期若白天玩偏多、晚间硬补 | ⚠️ 节奏易变成「变相作业日」 |
| 若听写一次 12 词 + 培优 60 分钟 + 多科并推 | ⚠️ 单日负荷要盯，别常态化 |

**一句话：** 方法对（闭环、减量、跟校内）；风险在某几天又叠成「小培训日」。

### 怎么判断「练得对不对」

1. **睡眠与情绪：** 能睡够、不太厌学 → 负荷大致 OK；经常哭闹、拖到很晚 → 减量。  
2. **是否服务校内：** 错字、计算、词句是为了跟课、写话、听写，不是超前刷整册。  
3. **有无终点：** 今天听写 8～10 词、销几个号就能停；没有「再做一本」的敞口任务。

### 双减版家庭边界（二年级）

- **工作日加练：** 校内作业后只选 **1～2 项**，合计约 **25～40 分钟**（含错字或口算或词句）。  
- **书面感要弱：** 错字本、词句本是「本子闭环」，不是每天整页练习册。  
- **周末：** 可稍整一点（听写一轮、绘本积累、应用题 1～2 题），仍留玩与运动。  
- **明确不做：** 再加学科班、整册一年级听写、双本计算日更、每天语数英全满。

### 结论（本节）

- **对：** 用错字本/错题本/词句本补「学校不留书面作业」后家里容易空掉的巩固与习惯——这是双减之后家长该补的，不是逆政策。  
- **不对：** 把家里做成「隐形全日制」——时长长、科目全、没有销号终点。  
- **砍与留：** 某周觉得紧，优先砍练习册页数、视频课时长；优先留错字本销号 + 短时口算 + 阅读/跟读。

## 二、感觉掌握不好、会落后，很焦虑，怎么办？

**提问背景（2026-08-28）：**  
感觉语文写字、英语词汇、数学计算与应用题都不好，专心度一般，担心比较落后。

### 结论

先把「感觉落后」和「实际位置」分开——按已有记录，**她不落后；短板是稳不稳、能不能自己启动**。

### 先用证据压一压焦虑

| 担心的 | 实际信号（画像 / 暑假复盘 / 日志） |
|--------|-----------------------------------|
| 语文写字差 | 一年级语文 **A**；错字本闭环能跑（双/走过关、春能回稳）；是**部分字不稳**，不是整册不会 |
| 英语词汇差 | 校内平板能跟；歌词语能认、one 已会拼；是**沉淀不够**，不是零基础 |
| 数学计算/应用题差 | 一下数学 **A+**；计算能日更；弱在**细心 + 应用题讲解**，上限够得着 |
| 专心度一般 | 有结构的任务（写字班、一页计算、数独）能完成；开放任务易散 → **任务设计问题**多于「不会学」 |

**一句话：** 期末能冲到 A/A+，说明能力在；焦虑来自「日常过程不漂亮」——这和「已经落后」不是一回事。

### 焦虑从哪来（对症）

1. **双减后家里更显眼：** 学校书面作业少，弱点全暴露在家里，容易误判成「全不会」。  
2. **一次看三科短板：** 写字 + 词句 + 应用题同时看，负荷感会放大。  
3. **和「理想二年级」比：** 其实该比的是**自己上周有没有销号**，不是同学超前多少。

### 怎么办：管焦虑 + 管学习，两条线

#### A. 管焦虑（家长侧）

- **每周只盯 1 个硬指标：** 例如「错字本销了几个号」，不要同时审判三科。  
- **用「本周最小包完成率」替代「掌握好不好」：** 做到 ≥70% 周数，对深中路径就是合格起步（见 [`概述.md`](概述.md)）。  
- **固定「停」：** 工作日加练到点就停；焦虑时想加量，反而证明该减量。  
- **记录进步，不只记错：** 如春回稳、one 会拼写、双/走过关——写进周小结，对抗「全是问题」的感觉。

#### B. 管学习（孩子侧 · 不另开战场）

继续已定抓手，**不要因焦虑加第四条线**：

| 科目 | 每周只保这个 | 暂时别做 |
|------|--------------|----------|
| 语文 | 错字本听写 ≥1 次，连对 3 次销号 | 整册一年级听写、每天一页拼音 |
| 英语 | 词句本指读 ≥2 次；顽固词小练 | 再加语法/体系课 |
| 数学 | 限时短计算 + 应用题 **1～2 题**（要能讲） | 培优加长课时、双本计算 |
| 专心 | 任务写清楚、有终点（「这 8 个词」） | 「把作业弄好」这种敞口催促 |

专心度：**短时块（25～35 分钟）+ 可见终点** 比「逼她专心一小时」有效——不是不能专心，是难在开放、漫长的任务里自启。

### 若两周后仍焦虑，用这个自测

连续两周问自己：

1. 待过关错字是否在减少（或至少没暴涨）？  
2. 词句本是否每周有碰？  
3. 应用题是否出现过「能讲清一道」？  
4. 睡眠/情绪是否大体正常？

- 若 1～3 有进展、4 还行 → **系统在工作，焦虑可降**。  
- 若 1～3 停滞且天天很晚、很凶 → 先减量保关系，再谈学习。

### 结论（本节）

- **落后？** 按年级评估，**不落后**；落后感主要来自过程毛糙和家长对照过强。  
- **怎么办？** 信任「结构化收紧」：少而硬、闭环销号；焦虑来时**加陪伴质量，不加册子**。  
- **真正危险的**不是「现在算得慢一点」，而是焦虑驱动下恢复题海，把刚跑通的错字本/词句本冲垮。  
- **允许用一学期把「会」变成「稳」**——二年级上学期正好干这件事。
