## 概述

### 这份文档是干什么的

本文档是小晴**小学阶段阅读记录本的专门说明**，和 [`日志-2026-08-暑假.md`](日志-2026-08-暑假.md) 5. 阅读（暑假盘点）、[`概述.md`](概述.md)（三科共识）分工不同：

| 文档 / 本子 | 角色 |
|-------------|------|
| **物理阅读记录本**（书桌） | **某本书/某册读完了**，记 1 行；孩子口头说一句，家长誊写 |
| **本文档** | 格式、规则、**学期书目台账**（§五）、方法优化（§七） |
| 每日学习日志 | 当天读了多久、读了什么（**过程**） |
| [`课外资源清单.md`](课外资源清单.md) | 家里有哪些书、在读/已读（**家长盘点**） |
| 暑假日志 2.4 | 阅读习惯、二上阅读方向（注音/漫画/桥梁合法） |

目标不是「写漂亮读后感」，而是学期末能回答：**读了哪些书、会不会讲一句、本数够不够**——为三四年级阅读量打底。

### 背景：为什么要单独做阅读记录本

2026 暑假阅读复盘结论：

- **有读：** 米吴 1–4 册、《337》至第 21 周、注音杂志若干；**8.25 米吴第 4 册亲子共读 15 分钟**。  
- **缺口：** 推荐无拼音整本未读；**没有统一本子记「读完」** → 学期末难统计本数、难复盘。  
- **孩子特点：** 注音/漫画肯读；无拼音整本抗拒 → 记录本**按册、按短篇**记，不逼大部头。

因此二上起：**过程写日志，读完写记录本**；不每天写、不要求摘抄。

### 已买的「1–2 年级带拼音阅读记录本」用不用？（2026-08-27 定）

家里已买专用本，栏目通常含：**阅读了什么 / 生字 / 词语 / 好句**（带拼音）。

| 判断 | 结论 |
|------|------|
| **本子本身** | **用得上**——当作物理阅读记录本即可，**不必再另买空白本**。带拼音适合她现阶段读注音/绘本。 |
| **栏目全填** | **现阶段用不上、也不建议**——每读一次就抄生字+词语+好句，会把阅读变成「又一份语文作业」；她写话已易拖、自启不稳，叠加后阅读天数先垮。 |
| **怎么用** | **轻量填**：必填「读了什么」+ 口头一句（可写在「好句」栏或旁白）；生字/词语**默认空**，偶尔才填。详见 **§一.1**。 |

**和错字本的分工（重要）：** 阅读里不会写的字 → **进错字本销号**，不在阅读本里另开一套「生字积累」。

### 核心思路（三句话）

1. **读完才记**——没读完只记在每日日志；读完当晚或周末花 **2～3 分钟**写 1 条（专用本最小栏）。  
2. **口头一句，笔头一行**——孩子说「最喜欢哪段」或 5W 一句，家长代写（二年级前期）。  
3. **物理本 + 本文档双轨**——本子上日常销号；本文档 §五 做学期汇总、与 [`课外资源清单.md`](课外资源清单.md) 对账。

**双轨流程：**

```
每天阅读 15 分钟（日志记过程）
    → 某本/某册读完
物理阅读记录本（专用本轻量填）
    → 学期末
本文档 §五 书目台账 + §六 统计
```

| 载体 | 谁用 | 更新频率 |
|------|------|----------|
| **1–2 年级带拼音阅读记录本**（已买） | 读完填最小栏；周末可翻一眼本数 | **读完当天或周末** |
| **本文档 §五** | 家长抄录或汇总学期书目 | 读完可同步；**学期末必做** |
| 每日日志 | 今天读了什么、多久 | 每天 |
| 课外资源清单 | 书从哪来、在读/已读 | 买书/借书时 |

## 一、用哪本本子

| 项目 | 建议 |
|------|------|
| **首选（已买）** | **1–2 年级带拼音阅读记录本**（含「阅读了什么 / 生字 / 词语 / 好句」）→ **轻量用**，见 §一.1 |
| 备选 | 普通空白本也可（§二 表头）；**二选一即可，不要两本并行** |
| 存放 | 书桌，和错字本、错题本、词句本放一起 |

### 1.1 已买专用本：栏目怎么填（二上执行版）

| 栏目 | 现阶段 | 怎么做 |
|------|--------|--------|
| **阅读了什么**（书名/日期等） | **必填** | 读完填；系列书写清第几册 |
| **好句** / 感想旁白 | **轻量** | 用孩子口头「最喜欢一句」或 5W 一句顶替；**家长可代写**；不会写的字用拼音 |
| **生字** | **默认不填** | 读时卡壳、听写错的字 → **进错字本**，不在这里另抄一串 |
| **词语** | **默认不填** | 最多 **每周 0～1 次**、每次 **1～2 个**她主动说「好玩/好听」的词；不考核背诵 |
| 读后感整页 | **不做** | 与写话「口述后写」抢时间；写话仍走每周 1 篇主线 |

**单次上限：** 读完后总耗时 **≤3～5 分钟**；超时就停，只留书名+口头一句。

**何时可以加「词语/好句」全量？** 等二上中后期：写话能当日收口、阅读 ≥5 天已稳 **≥6～8 周** 后再试「每周 1 本填 1 个好句」；仍不强制每篇生字栏。

### 和另外三本 + 文档怎么分工

| 本子 / 文档 | 记什么 |
|-------------|--------|
| **阅读记录本**（专用本轻量） | 某本书/某册**读完了**；口头一句 |
| **错字本** | 听写错的字 + 阅读里不会写、要掌握的字 → **销号**（不占阅读本「生字」栏） |
| 错题本 | 数学反复错的题 + 错因 |
| 词句本 | **英语**词句认读/听写，销号 |
| **每日日志** | 今天读了多久、读了什么（过程） |
| **课外资源清单** | 家里有哪些书、在读/已读（盘点） |

## 二、物理本格式

> 已用专用本时，**不必抄下面表头**；空白本或本子栏位不够时，可参考。

### 表头（空白本用）

```text
【小晴 · 阅读记录 · 二上】

日期        书名（可注第几册）    亲子/自己    一句话（最喜欢的情节 / 5W）
────────────────────────────────────────────────────────────────────
```

### 每条记什么（最小要求 · 与专用本对齐）

| 列 / 栏 | 写什么 | 示例 |
|---------|--------|------|
| **日期** | 读完当天 | 2026-09-05 |
| **书名** | 全名；系列书写清**第几册** | 米吴科学漫画 第5册 |
| **亲子/自己** | 谁为主读（本子无此栏可写在旁白） | 亲子 / 自己 |
| **一句话** | 最喜欢哪段，或 5W 一句（可写在「好句」栏） | 喜欢讲磁铁的章节；小猪骗大狼装树很好笑 |

**一句话可以是：**

- 最喜欢哪个角色 / 哪个情节  
- 或口头 **5W 一句**：「谁 + 做了什么 + 结果」

**二年级不要求：** 读后感、每篇摘抄、思维导图——太重，易把阅读变成作业。

### 物理本样例（空白本 / 或专用本「最小填」对照）

```text
【小晴 · 阅读记录 · 二上】

日期        书名                      亲子/自己    一句话
────────────────────────────────────────────────────────────────────
2026-08-25  米吴科学漫画 第4册          亲子        一人一页读了15分钟，喜欢××实验
2026-09-05  米吴科学漫画 第5册          亲子        喜欢里面讲磁铁的章节
2026-09-12  《小猪唏哩呼噜》上册        亲子        小猪骗大狼装树，很好笑
2026-09-20  成语·刻舟求剑（亲子读）      亲子        船走了还在原处找剑，很傻
2026-10-08  《猜猜我有多爱你》          亲子        小兔子说爱妈妈比天高
```

**专用本对应填法示例：**

| 栏 | 填 |
|----|----|
| 阅读了什么 | 《小猪唏哩呼噜》上册 · 2026-09-12 · 亲子 |
| 好句 | （口头）小猪骗大狼装树，很好笑 ← 家长代写 / 拼音可 |
| 生字 | （空）← 「骗」若不会写 → 进**错字本**，不抄这里 |
| 词语 | （空）或本周主动说的 1 个词 |

## 三、什么算「读完一本」

粒度要**前后一致**；二上以「孩子愿意读完、能讲一句」为准，不追无拼音大部头。

| 类型 | 怎么算「一本」 | 记法示例 |
|------|----------------|----------|
| 绘本 / 短篇童话 | 整本读完 | 《没头脑和不高兴》 |
| 漫画系列 | **一册**算一本 | 米吴第 4 册 |
| 注音杂志 | 不必每期记；**读完一期**或家长认定算一条 | 《课堂内外·低年级版》《世界儿童》2026-09（**8.30 到货**） |
| 桥梁书分册 | 按册或按「上/下」 | 《小猪唏哩呼噜》上册 |
| 成语故事 | 每周亲子 1 则：**可算阅读天数**；要留痕可写「成语·守株待兔」 | 成语·守株待兔 |
| 英文绘本 / 牛津树 | 若算阅读日，可记英文书名 | Oxford L2 · The Go-kart |

### 不算进阅读记录本

| 内容 | 记在哪 |
|------|--------|
| 《337》晨读 | 语文复习；日志可记「读了 337」 |
| 校内课文朗读 | 语文作业 |
| 只读了一半的书 | 只写每日日志，**读完再记本** |
| 英语词句 | [`英语词句积累学习方法.md`](英语词句积累学习方法.md) 词句本 |

### 学期目标（二上）

- **8～12 本**（含绘本、注音、漫画册、短童话）；见 [`2-3年级学习计划.md`](2-3年级学习计划.md)、[`二上逐周计划表.md`](二上逐周计划表.md)。  
- 漫画**一册一本**是合理计法。

## 四、什么时候写、谁写

| 时机 | 做法 |
|------|------|
| **读完当晚或周末** | 花 2～3 分钟写 1 行 |
| **没读完** | 只在每日日志记「今天读了 15 分钟」 |
| **谁写** | 二年级前期：**家长写书名和日期**，孩子**口头说一句**，家长誊写 |

### 5W 问法（读完 oral 检查）

不问「读懂了吗？」，问具体：

| 问法 | 示例 |
|------|------|
| **谁** | 故事里有谁？ |
| **做什么** | 他/她做了什么？ |
| **结果** | 最后怎么样了？ |
| **最喜欢** | 你最喜欢哪一段？为什么？ |

答出一句即可，不必五问全答。

### 家长话术

- 多问：「**谁？做了什么？结果怎样？**」「你最喜欢哪一段？」  
- 少问：「读懂了吗？」「写篇读后感。」  
- 表扬：**敢讲一句、愿意读完**，少强调「本月必须 12 本」。
