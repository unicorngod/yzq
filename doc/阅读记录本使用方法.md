# 小晴 · 阅读记录本使用方法

> **用途：** 小学阶段持续跟踪课外阅读——记「读完了什么」、学期本数、能否复述一句。  
> **原则：** 不是读书笔记；**读完记一行**，和错字本/错题本/词句本同一套「销号」逻辑。  
> **关联：** [`概述.md`](概述.md)｜[`课外资源清单.md`](课外资源清单.md)｜[`日志-2026-08-暑假.md`](日志-2026-08-暑假.md) **5. 阅读**｜[`二上逐周计划表.md`](二上逐周计划表.md)

**文档版本：** 2026-08-27 建｜起源：第 0 周建本需求；对齐二上阅读 ≥5 天×15 分钟、学期 8～12 本目标。

## 概述

### 这份文档是干什么的

本文档是小晴**小学阶段阅读记录本的专门说明**，和 [`日志-2026-08-暑假.md`](日志-2026-08-暑假.md) 5. 阅读（暑假盘点）、[`概述.md`](概述.md)（三科共识）分工不同：

| 文档 / 本子 | 角色 |
|-------------|------|
| **物理阅读记录本**（书桌） | **某本书/某册读完了**，记 1 行；孩子口头说一句，家长誊写 |
| **本文档** | 格式、规则、**学期书目台账**（§五）、方法优化（§七） |
| 每日学习日志 | 当天读了多久、读了什么（**过程**） |
| [`课外资源清单.md`](课外资源清单.md) | 家里有哪些书、在读/已读（**家长盘点**） |
| 暑假日志 2.4 | 阅读习惯、二上阅读方向（注音/漫画/桥梁合法） |

目标不是「写漂亮读后感」，而是学期末能回答：**读了哪些书、会不会讲一句、本数够不够**——为三四年级阅读量打底。

### 背景：为什么要单独做阅读记录本

2026 暑假阅读复盘结论：

- **有读：** 米吴 1–4 册、《337》至第 21 周、注音杂志若干；**8.25 米吴第 4 册亲子共读 15 分钟**。  
- **缺口：** 推荐无拼音整本未读；**没有统一本子记「读完」** → 学期末难统计本数、难复盘。  
- **孩子特点：** 注音/漫画肯读；无拼音整本抗拒 → 记录本**按册、按短篇**记，不逼大部头。

因此二上起：**过程写日志，读完写记录本**；不每天写、不要求摘抄。

### 核心思路（三句话）

1. **读完才记**——没读完只记在每日日志；读完当晚或周末花 **2～3 分钟**写 1 行。  
2. **口头一句，笔头一行**——孩子说「最喜欢哪段」或 5W 一句，家长代写（二年级前期）。  
3. **物理本 + 本文档双轨**——本子上日常销号；本文档 §五 做学期汇总、与 [`课外资源清单.md`](课外资源清单.md) 对账。

**双轨流程：**

```
每天阅读 15 分钟（日志记过程）
    → 某本/某册读完
物理阅读记录本（1 行：日期 + 书名 + 亲子/自己 + 一句话）
    → 学期末
本文档 §五 书目台账 + §六 统计
```

| 载体 | 谁用 | 更新频率 |
|------|------|----------|
| 空白本（书桌） | 读完记 1 行；周末可翻一眼本数 | **读完当天或周末** |
| **本文档 §五** | 家长抄录或汇总学期书目 | 读完可同步；**学期末必做** |
| 每日日志 | 今天读了什么、多久 | 每天 |
| 课外资源清单 | 书从哪来、在读/已读 | 买书/借书时 |

### 二年级上节奏（当前阶段）

| 时段 | 阅读方面做什么 |
|------|----------------|
| 8.27–8.31（第 0 周） | **买/定空白本**；封面写「二上阅读记录」；可补记暑假已读完的米吴 1–4 册（可选） |

**每周最小包（阅读相关）：** 阅读 **≥5 天 × 15 分钟**；**读完必记 1 行**（没读完不记）。

### 家长最快上手（3 步）

1. **买一本普通空白本**（A5/B5，线格或方格均可），封面写「小晴 · 阅读记录 · 二上」。  
2. **抄 §二 表头**到本子里前几页；读完一本让孩子**口头说一句**，家长写 1 行。  
3. **每周六**：翻本子数「本学期第几本」；学期末把书目抄进 §五 并写 §六 统计。

### 明确边界（概述级）

- ✅ 读完记 1 行；口头 5W 或「最喜欢一句」；漫画按册、绘本按本。  
- ❌ 每天写读后感、摘抄好词、画思维导图、没读完也记、和词句本混写。

## 二、物理本格式

### 表头（抄在本子前几页）

```text
【小晴 · 阅读记录 · 二上】

日期        书名（可注第几册）    亲子/自己    一句话（最喜欢的情节 / 5W）
────────────────────────────────────────────────────────────────────
```

### 每条记什么（最小 4 列）

| 列 | 写什么 | 示例 |
|----|--------|------|
| **日期** | 读完当天 | 2026-09-05 |
| **书名** | 全名；系列书写清**第几册** | 米吴科学漫画 第5册 |
| **亲子/自己** | 谁为主读 | 亲子 / 自己 |
| **一句话** | 最喜欢哪段，或 5W 一句 | 喜欢讲磁铁的章节；小猪骗大狼装树很好笑 |

**一句话可以是：**

- 最喜欢哪个角色 / 哪个情节  
- 或口头 **5W 一句**：「谁 + 做了什么 + 结果」

**二年级不要求：** 读后感、摘抄、思维导图——太重，易把阅读变成作业。

### 物理本样例（可直接照抄）

```text
【小晴 · 阅读记录 · 二上】

日期        书名                      亲子/自己    一句话
────────────────────────────────────────────────────────────────────
2026-08-25  米吴科学漫画 第4册          亲子        一人一页读了15分钟，喜欢××实验
2026-09-05  米吴科学漫画 第5册          亲子        喜欢里面讲磁铁的章节
2026-09-12  《小猪唏哩呼噜》上册        亲子        小猪骗大狼装树，很好笑
2026-09-20  成语·刻舟求剑（亲子读）      亲子        船走了还在原处找剑，很傻
2026-10-08  《猜猜我有多爱你》          亲子        小兔子说爱妈妈比天高
```

## 三、什么算「读完一本」

粒度要**前后一致**；二上以「孩子愿意读完、能讲一句」为准，不追无拼音大部头。

| 类型 | 怎么算「一本」 | 记法示例 |
|------|----------------|----------|
| 绘本 / 短篇童话 | 整本读完 | 《没头脑和不高兴》 |
| 漫画系列 | **一册**算一本 | 米吴第 4 册 |
| 注音杂志 | 不必每期记；**读完一期**或家长认定算一条 | 课堂内外注音版 2026-09 |
| 桥梁书分册 | 按册或按「上/下」 | 《小猪唏哩呼噜》上册 |
| 成语故事 | 每周亲子 1 则：**可算阅读天数**；要留痕可写「成语·守株待兔」 | 成语·守株待兔 |
| 英文绘本 / 牛津树 | 若算阅读日，可记英文书名 | Oxford L2 · The Go-kart |

### 不算进阅读记录本

| 内容 | 记在哪 |
|------|--------|
| 《337》晨读 | 语文复习；日志可记「读了 337」 |
| 校内课文朗读 | 语文作业 |
| 只读了一半的书 | 只写每日日志，**读完再记本** |
| 英语词句 | [`英语词句积累学习方法.md`](英语词句积累学习方法.md) 词句本 |

### 学期目标（二上）

- **8～12 本**（含绘本、注音、漫画册、短童话）；见 [`2-3年级学习计划.md`](2-3年级学习计划.md)、[`二上逐周计划表.md`](二上逐周计划表.md)。  
- 漫画**一册一本**是合理计法。

## 四、什么时候写、谁写

| 时机 | 做法 |
|------|------|
| **读完当晚或周末** | 花 2～3 分钟写 1 行 |
| **没读完** | 只在每日日志记「今天读了 15 分钟」 |
| **谁写** | 二年级前期：**家长写书名和日期**，孩子**口头说一句**，家长誊写 |

### 5W 问法（读完 oral 检查）

不问「读懂了吗？」，问具体：

| 问法 | 示例 |
|------|------|
| **谁** | 故事里有谁？ |
| **做什么** | 他/她做了什么？ |
| **结果** | 最后怎么样了？ |
| **最喜欢** | 你最喜欢哪一段？为什么？ |

答出一句即可，不必五问全答。

### 家长话术

- 多问：「**谁？做了什么？结果怎样？**」「你最喜欢哪一段？」  
- 少问：「读懂了吗？」「写篇读后感。」  
- 表扬：**敢讲一句、愿意读完**，少强调「本月必须 12 本」。

## 七、方法优化记录

| 日期 | 现象 | 调整 | 效果（后填） |
|------|------|------|--------------|
| 2026-08-27 | 暑假有读但无统一本子；推荐无拼音书抗拒 | 建阅读记录本；读完 1 行；漫画按册；不要求摘抄 | 待观察 |
| | | | |

**优化原则（备忘）**

- 本数远低于目标 → 检查是否要求太高（无拼音整本）；改注音/漫画/桥梁短册。  
- 孩子抵触「写」→ 只口头 5W，家长代写，不让孩子自己写读后感。  
- 记太勤（每读一次就写）→ 改回「读完才记」。  
- 与日志重复太累 → 过程只写日志，读完只写记录本。
