## 概述

### 这份文档是干什么的

本文档是小晴**小学阶段英语词句学习的专门跟踪本**，和 [`日志-2026-08-暑假.md`](日志-2026-08-暑假.md) 4.4（暑假总复盘）、[`概述.md`](概述.md)（三科共识）分工不同：

| 文档 | 角色 |
|------|------|
| **本文档** | 词句**怎么学、学了什么、熟不熟、学期怎么改**——长期维护 |
| 暑假日志 4.4 | 某阶段英语总评、资源取舍、二上方向 |
| 每日学习日志 | 当天做了什么（2～5 分钟打卡） |
| 课外资源清单 | 平板、牛津树、拼读、Hello English 等资源登记 |

目标不是「背多少单词」，而是建立一条可坚持 **6 年** 的闭环：**少量词句、反复过关、能读能写能用**——为三四年级读写加重打底。

### 背景：为什么要单独做词句积累

2026 暑假英语复盘结论（详见 4.4）：

- **输入不少：** 平板 20/20、牛津树 L2 33 课、拼读 L1、描红、26 字母过关。  
- **沉淀不够：** 除字母外未系统听写；描红是「看着写」，不等于「听音能拼」。  
- **已验证的路：** 8.23 看完《极地列车》后主动听唱主题歌，**看词跟唱** 7 词较清——说明不是「记不住」，是缺**窄词表 + 情感联结 + 复习闭环**。  
- **风险：** 若继续只加课（语法、HE 体系课、多刷牛津树）不复习词句，会长期「学过但不会」。

因此二上起：**不另开背单词线**，用 **词句本 + 听写 + 本文档台账**，逻辑对齐语文**错字本**（进本 → 复习 → 听写 → 销号）。

### 核心思路（三句话）

1. **词从现成学习里收**——校内平板、牛津树、拼读、英文歌；不另买大词书。  
2. **先认读、再听写、再销号**——入本满 3 天再听写；每次 5～8 词；待过关区不超过 25 词。  
3. **物理本 + 本文档双轨**——本子上孩子指读、听写；文档里家长记「学了什么、熟悉程度、学期统计」。

**双轨流程：**

```
学习输入（平板 / 牛津树 / 拼读 / 歌）
    → 圈词进本
物理词句本（待过关 ↔ 已销号）
    → 每周同步
本文档 §6 台账（英文 / 类型 / 熟悉度 / 听写记录）
    → 学期末
§7 统计 + §8 方法优化
```

| 载体 | 谁用 | 更新频率 |
|------|------|----------|
| 空白本（书桌） | 孩子指读、听写、订正 | 进新词当天；听写后 |
| **本文档 §6** | 家长填台账、改 L0～L5 | 进新词或周六复习时 |
| 本文档 §7 | 学期末汇总 | 每学期 1 次 |
| 本文档 §8 | 方法卡住时复盘 | 按需 |

## 一、要不要做词句听写

**暑假末现状**

| 已有 | 还没有 |
|------|--------|
| 26 字母默写过关 | 单词听写 / 默写（除字母外） |
| 一上课文衡水体描红 | 词句闭环 |
| 平板校内作业 20/20 | 从平板/牛津树/拼读收词进本 |
| 牛津树 L2、拼读 L1 认单词 | 听音→拼写输出 |
| 8.23 主题歌 8 词看词跟唱较清 | 8 词进本、隔日复习、试听写 |

**结论：应该引入。** 输入多、沉淀少；描红是「看着写」，不能替代听写。二上主线是 **词句本 + 听写**，不是再加单词书。

| 形式 | 做什么 | 二上优先级 |
|------|--------|------------|
| 认读 | 看英文能读、懂意思 | 最先 |
| 听写 | 听英文写英文 | 9 月底起，每周 2～3 次 |
| 默写 | 看中文/图写英文 | 10 月后再加 |
| 抄写 | 看着课文写 | 描红减量即可，不替代听写 |

## 二、方法与节奏

### 引入原则

1. 词从现成线路收：校内平板 → 牛津树每课 3 词 → 拼读例词 → 歌词语。  
2. 先会读再听写；入本 **≥3 天** 再纳入听写。  
3. 量要小：每次 **5～8 词**，每周 **2～3 次**，每次 **5～10 分钟**。  
4. 闭环：进本 → 隔日认读 → 听写 → 错词订正 2 遍 → 连续对 **2 次销号**。  
5. 工具：优先平板 **Hello English AI 听写**。

### 分阶段（二年级上参考）

| 阶段 | 时间 | 做什么 |
|------|------|--------|
| 0 · 建本 | 8.24–8.31 | 8.23 歌词语先入本；每天指读 |
| 1 · 认读 | 9 月第 1～3 周 | 5～10 词/周；指读 + 造句 |
| 2 · 听写 | 9 月第 4 周起 | 每周 2 次，每次 5 词 |
| 3 · 闭环 | 10 月起 | 听写纳入每周最小包；单元测对齐 |

### 单次听写流程（约 8 分钟）

1. 从待过关区抽 5～8 词（入本 ≥3 天）。  
2. 指读 + 说意思（1 分钟）。  
3. AI 或家长听写 → 当场订正错词 2 遍。  
4. 更新台账「熟悉程度」与「听写记录」。

### 与现有任务怎么排

- 校内平板第一；当天圈 **1～2 词**进本。  
- 牛津树每课 **3 词**；拼读当课 **1～2 词**。  
- 电影/歌：圈 **5～8 词**，每月 1～2 次。  
- 周六英语块末尾 **5～10 分钟**词句本；听写日与描红错开。

### 明确不做

- 不另买「每天 20 词」单词书、不刷百词斩当主线。  
- 不要求背完全册词表。  
- 不把抄写课文当单词记忆。  
- 听写日不叠 HE 体系课 + 整页描红。

## 三、本子与台账：怎么记

### 物理本（词句本）

| 区域 | 用途 |
|------|------|
| 待过关 | 未连续听写对 2 次的词；每周控制在 **15～25 词** |
| 已销号 | 听写过关或认读极熟的词 |

**分类：** 主结构 **按校内单元**（M1·U1…）；课文词与牛津/拼读/歌 **混排**；来源打标签（校内/牛津/拼读/歌）；**不按词性、不按纯日期**排整本。

**每条 5 列：** 英文｜意思｜来源｜例句/短语｜听写记录

### 本文档台账（与物理本同步）

物理本方便孩子指读；**本文档**方便家长跨学期统计、复盘、改方法。建议 **每周六** 或 **进新词当天** 同步一行。

## 四、熟悉程度（填写标准）

用 **L0～L5** 标记；每周复习时更新，听写后必改。

| 等级 | 名称 | 怎么判断 | 下一步 |
|------|------|----------|--------|
| **L0** | 新入本 | 刚写进本，还没复习 | 指读 1 遍 + 说意思 |
| **L1** | 指读 | 看词能读，意思大概懂 | 跟例句读；隔日再指读 |
| **L2** | 认读 | 看词能读且说清意思；能跟唱/跟句 | 口头造句 1 句；满 3 天可试听写 |
| **L3** | 半熟 | 听写错 1 次后订正能对；或脱词慢读 | 隔日再听写 1 次 |
| **L4** | 听写过关 | 连续听写对 **1** 次 | 再听写 1 次 → L5 |
| **L5** | 销号 | 连续听写对 **2** 次；或能主动造句运用 | 移已销号区；单元考前快刷 |

**短语 / 句子：** 同一套等级；短语可先停在 L2（认读+跟唱），不强制 L5。

**听写记录列写法：** `8.23入` → `9.12听✗` → `9.14听✓` → `9.16听✓` → **L5 销号**

## 五、选词标准

### 进本（每周新词总量 5～10）

| 优先级 | 条件 |
|--------|------|
| 1 | 校内单元核心词、平板反复出现、可能听写 |
| 2 | 听写错 / 认读卡壳 |
| 3 | 拼读当课例词（与校内重叠优先） |
| 4 | 牛津树每课 **3 个** |
| 5 | 歌/电影：看词跟唱已较清 |

### 不进本

纯听没看词；功能词 a/the/is（除非校内要求）；Oxford 一次 10+ 生词全收；8 字母以上长词（二年级先只认读）；从词书抄凑数。

### 词表三层（心里要有数）

| 层级 | 范围 | 要求 |
|------|------|------|
| A · 必认读 | 校内单元词 | 跟平板；能指读 |
| B · 必听写 | 每单元 5～10 核心词 | 词句本主线 |
| C · 加餐 | 歌、牛津、拼读 | 有则进本 |

## 八、方法优化记录（单独复盘）

> 每学期或遇到「课多记住少」时写一条；只改方法，不加量。

| 日期 | 现象 | 调整 | 效果（后填） |

**优化原则（备忘）**

- 待过关 >25 词 → **暂停进新词**，先销号。  
- 听写正确率 <60% → 减量（每次 3～5 词）或退回只认读 1 周。  
- 孩子抵触听写 → 检查是否入本未满 3 天就听写、或一次超过 8 词。  
- 三年级起 → 可适当增加短语、核心句；L5 标准可加「能造句」。
