### 每日「一科有多项」怎么写

同一科做了好几件事，**不要挤成一句说不清**，任选下面一种即可：

**写法 A（推荐）：同一行用** `；` **或** `①②③` **分隔**

```text
- 英语：① 描红一页（一上课文）；② 跟读录音 5 分钟；③ 字母书写半页
- 阅读：① 《猜猜我有多爱你》亲子共读；② 口头说了最喜欢的一页
```

**写法 B：缩进子项（事项多、想写细时用）**

```text
- 英语：
  - 描红一页（一上课文）
  - 跟读录音 5 分钟
  - 字母书写半页
- 阅读：无
```

**写法 C：多项里有对错/进度时，把结果写在后面**

```text
- 数学：① 口算 28 题，错 3 题已订正；② 退位减竖式 4 题全对
```

注意：科目名（语文/数学/英语/阅读）仍各占一条 `- 语文：`，多项写在冒号后面或缩进子项里。

# 2026 暑假总体完成情况（家长填写）

> 暑假大致区间：××××年××月××日 ～ 2026-08-31（可改）  
> 用途：开学前一次性盘点「暑假到底完成了什么」，方便和二上计划对照、后续一起总结。  
> 填法：能写数字写数字，能列清单列清单；没有的写「无」或「未做」。  
> **三类来源分开写（不要混在一格）：**  
> ① **校内暑假作业** → 各科「x.1」  
> ② **课外教程/辅导班** → 各科「x.2」+ 第 7 节兴趣班  
> ③ **家长补充作业**（自己买的练习册、听写、口算纸、布置的阅读等）→ 各科「x.3」  
> 课外教程请尽量写清：教程名、平台、学到哪、具体知识点条列（每科下有示例，填完可删示例）。

### 二、画像解读（多看一层）



#### 1. 她是什么类型的学习者（就数学而言）

- **耐力型 / 任务型：** 黄冈 + 学而思计算几乎日更、能订正，说明「规定清楚、每天固定做」时，数学执行力可以很好——这和语文加练「偷工减料」形成对照：不是不能坚持，而是**任务是否具体、是否有可见页数终点**很关键。
- **形象与操作尚可：** 长度测量试课掌握较好；8.23「量一量」与家长一起能完成；数独全对 → 空间/逻辑在结构化任务里能发挥；**实操类需家长陪着启动**。
- **脚手架型：** 8.23 圆片平均分 2/3/4/6 份——家长带画图、表达、列式、讲题后**能自己做对** → 不是不会，而是**独立读题、画图、列式**缺步骤；与语文「口述后概括再写」同型，二上应用题宜「带做→半独立→检查」。
- **语言转数学偏弱：** 应用题理解卡壳、暑假作业应用题错过 → 瓶颈多在**读懂题意、抓住数量关系**，不只是算式对不对；圆片分份题印证「讲清后能算对」。
- **粗心 ≠ 不会：** 数独全对，计算却常错 1–3；**一下平时测验常 B/B+、期末数学 A+** → 天花板够得着顶尖档，缺口是日常稳定发挥。**8.24** 能总结错因 → 二上错题本方向对。
- **「平时 B、期末 A+」怎么理解：** 不要因期末惊喜加超前；也不要只盯平时 B 否定潜力。二上把单元测/限时练当「小期末」，把正确率往期末靠。



#### 2. 「练了很多但仍常错」怎么理解

- 每天 40–45 题 + 再 22 题，总量很大，**正确率却未随题量明显抬到「大多全对」**，说明当前练法主要强化了「做完习惯」，对「准确习惯」刺激不够。
- 全对有时能出现（约三成或五六次），证明能力天花板够得着；缺口是**稳定发挥**，适合用「限时 + 全对奖励/错题归因」而不是继续加页。
- 订正有做，是加分项；**8.24 开始能口头总结错因**（如 16+(16-8) 只算括号内、退位忘了）→ 比只改答案进一步；二上错题本要求「错因一句话」常态化。
- 若订正停留在「改成正确答案」而未写「错因」，粗心会反复回来。



#### 3. 乘法进度：不大超前，也不算空

- 已建立「乘法原理」和「5 的口诀/应用」，且能做对 → 二上表内乘法不是零起步。
- 家长自判「预习没完成」是对的：2–4、6–9 尚未系统铺开；**这恰好适合跟校内走**，避免暑假超前学完、开学松懈或概念夹生。
- 风险反而是：若二上既跟校内、又想把培优/乘法册赶进度，会和「减量提质」打架。



#### 4. 应用题：暑假暴露的核心短板

- 1 对 1 明确「仍卡壳：应用题理解」；暑假作业也错过应用题 → 证据一致。
- 8.23 圆片平均分：经家长指导画图、列式、讲题后**能自己做对** → 短板在**独立启动**，不在算式本身；二上宜固定「读题→画图→列式→讲一句」流程，而非加更多纯计算。
- 计算天天练、应用题练得少，会加剧「会算不会用」。
- 二上长度、乘法、平均分应用题都会上来，**现在补「画图讲理」比补更多竖式更划算**。



#### 5. 资源结构是否健康


| 资源        | 作用       | 评价             |
| --------- | -------- | -------------- |
| 每日计算双本    | 习惯与熟练    | 暑假有效；二上应减量，防疲劳 |
| 培优学习机 15% | 思维拓展     | 可保留为支线；图形项是兴趣点 |
| 乘法材料      | 衔接二上重点单元 | 价值高，宜同步校内      |
| 1 对 1 试课  | 摸底       | 已完成使命（知强弱、定不续） |
| 数独        | 自信与专注    | 可作调剂，勿替代应用题    |




#### 6. 风险与机会（二上视角）

- **机会：** 已有日更肌肉；长度不陌生；5 的乘法有底；不续一对一省下时间给错题本与应用题。
- **风险 1：** 开学后校内作业 + 仍双本计算 → 厌学或敷衍，正确率更差。  
- **风险 2：** 只追口诀背诵、应用题继续靠蒙运算符号。  
- **风险 3：** 培优进度焦虑（15% 想追完）挤占校内与订正时间。

#### 3.1 校内（作业小超市，约 85%）

- **计算题：** 自选坚持每天；约 30% 全对，常错 1–3/20，有订正 → **习惯分高、准确分中上**。建议开始记录「错因」而不只改答案。

#### 3.2 课外课

- **A 线下 1 对 1 试课（4 节，不续）：**  
  - 收获：摸清「长度 OK、应用题弱、乘法拉开了头」。  
  - 决策：不续 —— 正确。计算已有家庭日更，再 1 对 1 边际低；把钱和时间留给「应用题精讲式陪伴」（家长画图带讲即可）。
- **B 学而思学习机培优·二级（对应一下，约 16%，接着看）：**  
  - 内容含代换、巧算、图形、移多补少，偏思维；「掌握较好：图形叠加」可当作自信区。  
  - **不跳三级：** 与语文秘籍同理——虽已升二上，仍先夯二级；跳级易空心，且思维题仍需脚手架（8.24 知给求差）。  
  - 16% 不必焦虑：培优是加分项不是主粮；二上每周 ≤1～2 节；**二级全部上完后再开三级**。
- **C 学而思乘法（同步进行）：**  
  - 定位应改为「校内乘法的家庭配套」，而不是「暑假超前工程」。  
  - 5 的口诀先熟到脱口，再按教材进 2、3、4、6…



#### 3.3 家长补充（完成度高，「会但常错」）

- **黄冈 + 学而思计算双线日更：** 暑假最大成功，也埋下「题海依赖」隐患——孩子可能习惯用「做完」换认可，而不是用「全对」换认可。二上家长评价口令建议从「做完了吗」改为「全对了吗 / 错题讲清楚了吗」。
- **8.25 黄冈小状元作业本（语数英）到货：** 定位为**校内配套**，替代「另开一本大计算」；开学后跟单元页，不恢复暑假双本题海。
- **学而思暑假作业应用题错过：** 与试课结论互相印证，应用题必须单列进每周包。
- **乘法两单元能做对：** 质量好于进度；保持「做对优先于做快、做多」。

### 二、画像解读（多看一层）



#### 1. 她是什么类型的学习者（就英语而言）

- **视听型 / 跟读型：** 平板全完成、牛津树 L2 33 课、描红+拼读 → 对**视频、音频、歌曲**接受度高。
- **兴趣自驱型（8.23 坐实）：** 看完《极地列车》后**主动听唱**主题歌 30+ 遍、跟哼十几次；**不用催**——有情节、有好歌时自启强于牛津树作业式跟读。
- **看词跟唱型（新发现）：** 教唱前 7 句、看歌词跟唱十几次后，**wishing / star / trying / believe / far / children / town** 等词发音较清晰、懂意思；整段约 2～3 句清，其余仍模糊 → **有画面+有歌词**比纯听更容易留住词。
- **爱看电影：** 能完整专注看完；迪士尼等熟故事 + 主题歌是合适切口。
- **记忆规律：** 校内词句、牛津树词仍弱；但**歌里 8 词**说明不是「完全记不住」，而是缺**窄而深、带情感**的复习闭环；纯听 30 遍不圈词仍不够。
- **书写在进步：** 字母、描红能坚持 → 固定小任务有效。
- **与数学对比：** 数学靠日更计算闭环；英语可用**「一首歌 8 词、每周复习」**小闭环，不必先铺大课。



#### 2. 「课多、记住少」怎么理解

- 同时有：平板、牛津树 L2、拼读 L1、语法视频、衡水体描红、字母默写 → **资源偏多**，家长补充后期又松。
- 牛津树 33 课偏故事跟读，若少做「读后说几句 / 圈核心词」，词句不易沉淀。
- 拼读 L1 四个短元音是正确起点，要配**见词能读的小词表**，否则与校内单词脱节。
- 语法课（a/an、What's this）对二年级过早且频率太低，二上宜**暂停或极低频**。



#### 3. 校内与课外是否对齐

- 校内平板 15 分钟/天完成好 → **学校线上任务能跟**。
- 牛津树 L2 替代绘本作业 → 策略对，算阅读+英语双收。
- 「基础不够」多半指**校内词句未内化**，不是完全没学英语。



#### 4. 风险与机会（二上视角）

- **机会：** 敢跟读、平板全勤、字母过关、拼读有短元音底；**电影/英文歌能自启**（8.23 验证）。
- **机会 2：** 迪士尼等情节熟、歌词清的片子，适合「看+唱」；不必一上来全英无字幕硬扛。
- **机会 3：** 8.23 已沉淀 **8 个歌词语** + 看词跟唱法 → 可直接作为**词句本第一批**，比从零听写校内词阻力小。
- **风险 1：** 继续加新课不做词句复习 → 永远「学过」不「会用」。  
- **风险 2：** 牛津树/电影**只追看完、不圈词不跟唱** → 热闹一场，词句仍空。  
- **风险 3：** 与语数抢时间，英语变「有空才看」；或**周末连看多部迪士尼**挤掉听写。

#### 6. 兴趣输入：电影与英文歌（8.23 验证 · 二上可执行）

**结论：可以偶尔加，而且值得加——但是「兴趣加餐」，不是第四条英语课。**

**8.23《极地列车》实录（暑假英语兴趣路径样板）：**

1. 完整专注看完电影 → 爱上主题歌 When Christmas Comes to Town。
2. **主动**听 30+ 遍、跟哼十几次（无需催）。
3. 家长教唱**前 7 句**一段，跟唱十几次。
4. **看歌词跟唱**：wishing / star / trying / believe / far / children / town — 教了意思，**看词发音较清晰**；整段约 2～3 句清，其余仍模糊。
5. **启示：** 有情感联结 + 看词指读，比纯听牛津树更容易留住词；下一步是**进词句本、隔日复习、试脱词**。


| 做法       | 建议                                                                                     |
| -------- | -------------------------------------------------------------------------------------- |
| **频率**   | 每月 1～2 次（周末/假期）；看完 1 部配 1 首歌                                                           |
| **选片**   | 迪士尼/皮克斯等故事熟的；二年级可英音轨+中文字幕                                                              |
| **单次流程** | ① 选 1 首歌的前 4～8 句；② 看歌词跟唱 5～10 遍；③ **圈 5～8 词进词句本**（8.23 已示范）；④ 隔天复习 1 次；⑤ 试说 1 句（中英混合可） |
| **与牛津树** | 电影周可替代 1 次牛津树；校内平板仍第一                                                                  |
| **明确不做** | 不连刷多部；不要求背全歌词；只听不圈词                                                                    |


**迪士尼/原版电影的价值：** 语感、节奏、文化直觉。**歌+看词跟唱的价值：** 8.23 证明比暑假任何一节语法课都更愿开口。收束到词句本才算学英语，否则只是娱乐。

### 缺口分析：成语要不要开学后补？


| 判断            | 结论                                                                 |
| ------------- | ------------------------------------------------------------------ |
| **重要性（二上）**   | **低**。不进硬底线；服务语感与以后词语，不考核背诵。                                       |
