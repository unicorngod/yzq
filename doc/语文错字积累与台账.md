# 小晴 · 语文错字积累与台账

> **用途：** 小学阶段持续跟踪**会写字**听写、书写错误——方法、错字台账、销号、与人教版写字表对照。

## 概述

### 这份文档是干什么的


| 文档 / 本子                        | 角色                                  |
| ------------------------------ | ----------------------------------- |
| **物理错字本**（书桌）                  | 孩子抄写 5 遍、组词、听写订正                    |
| **本文档 §六**                     | 家长记**哪些字、错因、听写记录、是否销号**——跨学期统计      |
| 每日学习日志                         | 当天听写几句、错几个（过程）                      |
| **§七～§十一**                     | **人教版统编**一～二年级**会写字**按阶段/课文对照 + 核心词 |
| 暑假日志 2.4                       | 语文总评、二上方向                           |
| `[阅读记录本使用方法.md](阅读记录本使用方法.md)` | 阅读里不会写的字 → **进错字本**，不占阅读本「生字栏」      |


目标：课内听写跟得上、写话少因生字卡住；学期末能看清**顽固字**和**已销号字**。

### 核心思路（三句话）

1. **只收「要会写」的字**——课内写字表、听写错、写话/拼音写字不会写的字；不认读表、不整册抄。
2. **过关才移出**——连续听写对（建议 **4 次书写正确** 或 **3 次听写全对**）再销号；顽固字（如 **春**）拉长复习，一次不过不放弃。
3. **物理本 + 本文档双轨**——本子上练；文档里记来源、错因、听写日期。

**双轨流程：**

```
听写 / 写字 / 写话 / 拼音写字
    → 写错或不会写
物理错字本（待过关：5遍+组词+听写）
    → 每周同步
本文档 §六 错字台账（字 / 来源 / 错因 / 听写记录 / 销号）
    → 对照
§七～§十一 人教版写字表（该字属哪一课、核心词）
```



### 熟悉程度（S0～S5）


| 等级     | 名称   | 怎么判断                       | 下一步               |
| ------ | ---- | -------------------------- | ----------------- |
| **S0** | 新入本  | 刚写进本，还没练                   | 抄 5 遍 + 组词 1 个    |
| **S1** | 练过   | 抄过 5 遍，还没听写                | 隔日听写 1 次          |
| **S2** | 听写错过 | 听写错 1 次，已订正                | 再听写；形近字放一起对比      |
| **S3** | 半熟   | 听写对 1～2 次，或书写仍偶错           | 继续听写；顽固字加「词中写」    |
| **S4** | 待销号  | 连续 **3 次听写对** 或 **4 次书写对** | 再测 1 次 → S5       |
| **S5** | 销号   | 连续过关；单元考前快刷即可              | 移物理本「已销号」区；本文档标 ✓ |


**听写记录列写法：** `8.27入` → `8.28听✗` → `8.29写×4✓` → `8.30听✓` → **S5 销号**

### 错因标签（与测验台账对齐）


| 标签   | 含义            | 练法         |
| ---- | ------------- | ---------- |
| `字形` | 形近写错（公→工、母→每） | 形近字对比抄     |
| `笔顺` | 部首/笔顺错        | 描红 3 遍     |
| `不会` | 完全不会写         | 5 遍+组词+看词写 |
| `拼音` | 声母韵母混（亲→qing） | 对比练，不单抄字   |
| `粗心` | 会写但听写错        | 词中听写，少怪字   |

## 一、物理错字本格式


| 区域      | 用途                      |
| ------- | ----------------------- |
| **待过关** | 未达 S5 的字；建议同时 **≤25 字** |
| **已销号** | S5 过关的字（期末考前可快刷）        |


**每条建议写：** 汉字｜组词｜听写记录（日期✓/✗）｜来源（校内/暑假/写话）

**与拼音易混：** 可在字旁用铅笔标正确拼音（如 亲 qīn），不另开一本拼音本。

## 二、什么字进本 / 不进本


| 优先级 | 进本条件                        |
| --- | --------------------------- |
| 1   | 课内**写字表**听写错                |
| 2   | 写话、日记里不会写、用拼音代替的字           |
| 3   | 拼音写字（看拼音写字）不会写或写错的**课内必写字** |
| 4   | 形近字反复混（公/工、母/每）             |



| 不进本       | 原因            |
| --------- | ------------- |
| 只认不写（识字表） | 二上主攻「会写」      |
| 阅读记录本里的字  | 阅读本只记读完；字进错字本 |
| 一次写对的字    | 不预防性收录        |

## 三、单次听写流程（约 8 分钟）

1. 从待过关区抽 **5～10 字**（含 1～2 个顽固字如 **春**）。
2. 口头组词 1 个 → **词中听写**（如「春天」的「春」）。
3. 错的：订正 2 遍，标回本子，本文档改 S2/S3。
4. 全对：听写记录 `✓`，累计 toward S4/S5。

### 6.0 一年级历史错字迁入（第 0 周）

> **做什么：** 把一上、一下资料里**曾经错过**的字，统一写进现在的错字本，再按 §三 听写销号。  
> **不做什么：** 不把约 200 个会写字整册再考一遍；**已 S5 销号**（如双、走）除非再错，不拉回待过关。



#### 三步流程


| 步            | 做什么                                                           | 约多久   |
| ------------ | ------------------------------------------------------------- | ----- |
| **1 · 抄清单**  | 按下面「去哪里找」翻旧资料，只记**写错过/听写错过**的字（去重）                            | 1 个晚上 |
| **2 · 写入双轨** | 每字抄进**物理错字本**待过关区 + 本文档 **§6.1** 加一行（S0 起）；用 §八、§九 填「课文/阶段」   | 同上    |
| **3 · 听写销号** | 第 0 周听写 **2 次**（每次 8～10 字，词中听写）；9 月起每周 ≥1 次；待过关 **>25 字暂停加新** | 开学前起  |
