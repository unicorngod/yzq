## 一、阶段总目标（2–3 年级）

| 维度 | 目标（期末可自测） |
|------|-------------------|
| 语文 | 识字量达标并略超课标；能独立读整本儿童章节书；作文能写清一件事（3 年级） |
| 数学 | 课内满分**稳定**（不只期末一次）；口算又快又准；应用题会画图、讲思路 |
| 英语 | 听说不怯场；二年级末课内词句能认读+核心词可听写；三年级末能读简单绘本/短文 |
| 习惯 | 每天固定启动块；作业独立；错字/错题/词句本会销号 |

**不做：** 大量刷奥赛卷、超前学四五年级整册、同时报过多兴趣班、再开第四条英语视频线。  
**要做：** 课内扎实 + 阅读习惯 + 三科各 **1 条主线闭环**（错字本 / 错题本 / 词句本）+ 数学思维启蒙（每周少量）。

**暑假验证（家底约 3～4 分）：** 能力在、自启不稳；8.22–8.23 证明「任务设计对了就能做完」。  
**一年级成绩锚点：** 一上英语/美术/劳动 A+，其余 A；一下数学/科学 A+，其余 A 档；课堂倾听/记录 A、表达 B。数学平时常 B/B+ → 二上盯过程稳定 + 轻量练课上开口（详见画像 §〇）。

## 二、每日/每周时间骨架（适配有弟弟的家庭）

### 工作日（建议总计 60–90 分钟，含作业）

| 时段 | 内容 | 时长 |
|------|------|------|
| 放学后 | **点心 15 分钟** → 再写校内作业 | 作业自定 |
| 作业后学习块 | 加练只选 **1～2 项**（见下方最小包） | **25～35 分钟** |
| 睡前 | 亲子共读或孩子自读 | 15–20 分钟 |

**学习块怎么选（二上）：** 错字本听写 / 限时口算或 1～2 道应用题 / 英语跟读或词句本指读——**不每天语数英全满**。语文写话、古诗：**每周 1～2 个重点块**；**秘籍每周 1 节**（1 级→2 级→3 级），不每天摊大饼。

### 周末（每周固定即可，不必天天满档）

| 内容 | 时长 | 说明 |
|------|------|------|
| 英语：校内/跟读 + **词句本** + 牛津树或拼读 | 40–50 分钟 | 可拆成 2 次；听写日与描红错开 |
| 数学思维题 / 错题回顾 | 30 分钟 | 重质量不重张数；应用题画图讲理 |
| 语文阅读 + 口头复述（或写话 1 篇） | 30–40 分钟 | 写话走口述→概括→誊写 |
| 运动/户外 | ≥1 小时 | 保专注力与睡眠 |

### 每周最小包（二上硬底线 · 与概述一致）

| 科目 | 必做 |
|------|------|
| 语文 | 错字本销号 ≥1 次；阅读 ≥5 天×15 分钟（**可含每周 1 则成语故事亲子读**）；写话 1 篇（口述后写） |
| 数学 | 限时计算（减量）+ 错题本；应用题 **秘籍专项 1～2 题/周**（画图讲清） |
| 英语 | 校内第一；词句本 ≥2 次/周；跟读 ≥4 天 |

**合格线：** 最小包稳定做到 **≥70% 周数** 即合格起步；做不到先减量收紧，不加量。

**原则：** 大人能陪就陪「讲思路」；不能陪就留「可独立完成」的任务（口算、听读、词句指读）。家长少问「学了多少」，多问「今天最小包哪一项完成了」。

## 三、二年级：分科知识点 + 掌握方法

### 3.1 语文（二年级）

> 二上抓手：**错字本闭环** + **口述→概括→誊写**（说长写短）+ 有拼音阅读。详见暑假日志 **2.4**。

#### 必须掌握的知识点

1. **识字写字**
   - 课标要求约再增识 1000 字左右（累计约 1600–2000）；会写常用字约 800–1000
   - 音序查字法、部首查字法会用
   - 同音字、形近字、多音字能区分（如：再/在、的/地/得 初步）

2. **词语与句子**
   - 词语搭配、近义/反义、量词
   - 把字句、被字句、疑问句、感叹句
   - 能把乱序词排成通顺句子

3. **阅读**
   - 课内：短文能找关键词、答简单问题（谁、做了什么、为什么）
   - 课外：能读带拼音/少量生字的桥梁书 → 过渡到无拼音章节书

4. **表达与写话**
   - 看图写话：写清楚时间、地点、人物、经过、结果
   - 能用「因为……所以……」「先……再……然后……」组织句子
   - 日记/周记：3–5 句通顺即可（口述可长，誊写要精）

5. **朗读与积累**
   - 课内课文流利有感情朗读
   - 课内古诗/日积月累会背会默；已会古诗以复习为主，不追假期债清零

#### 掌握方法

| 知识点 | 方法 | 家长怎么做 |
|--------|------|------------|
| 生字词 | 「听写—错字本—二次听写」闭环；形近字放一起对比写 | 每周销号 ≥1；不天天默整本 |
| 拼音 | **取消每天一页硬指标**；只服务错字/听写，隔天或按需 | 暑假已验证「每天一页」易偷工 |
| 查字典 | 每周刻意练 3–5 个生字查字典 | 先示范再放手 |
| 阅读理解 | 读完用「5W」口头问答 | 不问「读懂了吗」，问具体问题 |
| 写话 | **聊 3～5 分钟 → 口述（可长）→ 家长帮概括、留 1～2 个镜头 → 誊写**（生字可拼音）→ 不会的字进错字本 | 改「通顺+具体」，少改文采；说长写短 |
| 朗读 | 录音对比、或亲子接读 | 每天可只读 1 段课文 |

**二年级阅读阶梯（举例）：**  
《猜猜我有多爱你》等绘本 → 《小猪唏哩呼噜》《没头脑和不高兴》→ 《亲爱的汉修先生》《小狐狸买手套》等桥梁书；注音杂志、337 小块可续。

### 3.2 数学（二年级）

> 二上抓手：**限时计算（减量）** + **错题本** + **应用题画图讲理**。详见暑假日志 **3.4**。

#### 必须掌握的知识点

1. **数与运算**
   - 100 以内加减（含进退位）熟练；表内乘除法（乘法口诀）滚瓜烂熟
   - 有余数除法：理解「余数比除数小」
   - 万以内数的认识、读写、大小比较（按教材进度）
   - 混合运算顺序（先乘除后加减；有括号先算括号）

2. **量与计量**
   - 米/厘米、千克/克的初步认识与简单换算
   - 时、分、秒；会看钟面到「几时几分」

3. **图形与几何**
   - 角的初步认识；直角、锐角、钝角直觉判断
   - 轴对称初步；简单方向与位置（东南西北入门视教材）

4. **统计与问题解决**
   - 简单统计表、条形图读图
   - 应用题类型：求和、求差、求剩余、求倍数（初步）、两步应用题

#### 掌握方法

| 知识点 | 方法 | 自测标准 |
|--------|------|----------|
| 口算/口诀 | **限时**小口算（3–5 分钟）；错题次日重做；黄冈/学而思计算 **轮换**，不两本每天满页 | 乘法口诀任意抽问反应快 |
| 进退位/有余数 | 用小棒/钱币实物演示再抽象到竖式 | 能讲「为什么要进位/余数是几」 |
| 应用题 | **每周 1～2 题精做**（《学而思秘籍·应用题专项突破》二年级 + 思维闯关）：画线段图 + 讲算理，再动笔；校内有同类错题可计入，总量约 2～3 道/周；禁止只会套公式 | 合上书能讲清「先求什么、再求什么」 |
| 易错点 | 建「错题本」：只抄题干+正确解法+一句话原因 | 同类错一周内不再犯 |
| 家长话术 | 少问「做完了吗」 | 多问「全对了吗 / 错题讲清楚了吗」 |

**思维启蒙（每周 1 次，30 分钟即可）：**  
找规律、简单逻辑推理、数一数（图形计数）、等量代换。材料可选校内拓展或《学而思》低年级思维训练中的「基础册」，以「讲明白」为准，不赶进度。培优是加分项不是主粮。

### 3.3 英语（二年级）

> 教材：**沪教牛津版（深圳用）**（2024 多为 6 Unit；旧版为 4 Module·12 Unit，见逐周计划附录 D）。  
> 二上抓手：校内平板第一 + **词句本** + 牛津树/拼读重质量。详见 **4.4** 与 [`英语词句积累学习方法.md`](英语词句积累学习方法.md)。

#### 必须掌握的知识点

1. **语音**：26 字母大小写；常见字母组合自然拼读（短元音等；如 sh/ch/th 入门）
2. **词汇**：教材单元词会听、说、认读；核心词逐步可听写；课外词进词句本（歌/牛津树/拼读）
3. **句型**：教材单元句型；打招呼、家庭、学校等（以校内 Unit 为准）
4. **听说**：能跟读课文录音；能听懂课堂指令与简单故事；敢开口

#### 掌握方法

| 目标 | 方法 |
|------|------|
| 发音 | 跟读教材音频；每周可录音对比 1 次 |
| 拼读 | 新东方拼读 L1 等按课推进，每天/每周少量「见词能读」；例词可进词句本 |
| 词汇 | **词句本按单元收词**（校内+课外混排）；先认读，9 月底起听写 5～8 词/次；熟悉度 L0～L5 |
| 拼写/听写 | 描红减量练字形；听写走词句闭环；Hello English **仅 AI 听写工具**（体系课 9 月先不开） |
| 牛津树 | 每周 2～3 节；跟读 + 说 2～3 句 + **圈 3 词进本**（不追看完多少集） |
| 兴趣加餐 | 英文电影 + 主题歌：**每月 1～2 次**；看词跟唱 + 圈 5～8 词进本（8.23 已验证） |

**明确不做：** 另开背单词书/百词斩当主线；语法视频与 HE 体系课叠加牛津树；只看电影不圈词。

## 四、三年级：分科知识点 + 掌握方法

> 三年级是分水岭：作文独立成篇、数学多位数运算与分数入门、英语读写加重。习惯比分数更重要。  
> 二年级若最小包与三本闭环已稳，三年级再加难度；若仍像暑假加练执行偏低，**先收紧再加量**。

### 4.1 语文（三年级）

#### 必须掌握的知识点

1. **识字写字**：累计识字约 2500；会写约 1500–2000；行款整齐、错别字明显下降  
2. **词语**：成语、关联词（不但……而且……、虽然……但是……、如果……就……）  
3. **阅读**：
   - 概括主要内容（谁做了什么）
   - 理解关键词句表情达意
   - 分辨记叙文六要素；初步接触说明文「抓住事物特点」
4. **习作**（核心能力）：
   - 写人、写事、写景物，400 字左右能写完
   - 有开头结尾；过程有细节（动作、语言、心理择一写好）
   - 会修改：通顺、删重复、补具体
5. **积累**：古诗文按课标；好词好句本（摘抄+仿写一句）

#### 掌握方法

| 知识点 | 方法 |
|--------|------|
| 作文 | 「素材本」：每周记 2 件真实小事；作文前先列提纲；仍可先口述再写 |
| 阅读理解 | 每周 1 篇短文精读：划找答案出处；答案用原文词改写 |
| 错别字 | 错字本逻辑延续；作文/听写错字当日订正（词中写，不单写字） |
| 课外阅读 | 目标：**一学期 8–12 本**适龄书；读完口头或书面「推荐卡」 |

**三年级书单方向：** 《时代广场的蟋蟀》《窗边的小豆豆》《亲爱的笨笨猪》《了不起的狐狸爸爸》《宝葫芦的秘密》等；可穿插科普（《昆虫记》少儿版）与深圳/中国地理童书。

### 4.2 数学（三年级）

#### 必须掌握的知识点

1. **数与运算**
   - 万以内加减；两/三位数乘一位数、两位数；除数是一位数的除法
   - 估算意识（大约多少）
   - 分数的初步认识（几分之一、简单比较）
2. **量与计量**：千米、吨；时分秒运算；面积初步（长方形/正方形面积公式理解，不只背）
3. **几何**：周长；长方形正方形特征；平移旋转直观
4. **应用题**：多步题；归一/归总初步；简单行程「速度×时间=路程」入门（视教材）
5. **数学广角/思维**：排列组合初步、逻辑推理、简单容斥直觉（课内有则吃透）

#### 掌握方法

| 知识点 | 方法 |
|--------|------|
| 多位数乘除 | 竖式步骤口诀化；每日少量**限时**练；错题本延续 |
| 面积周长 | 先用方格纸量、再抽象公式；对比「围一圈」和「铺满」 |
| 分数 | 用圆形/长方形纸折分；强调「平均分」 |
| 应用题 | 继续线段图；自己编一道同型题讲给家长听 |
| 竞赛向 | 仍以思维课为主；若学有余力，再接触低年级杯赛「简单题」，不整本硬刷 |

**三年级末自测：** 课内单元卷稳定 95+；口算几乎不失分；应用题不会「蒙运算符号」。

---

### 4.3 英语（三年级）

#### 必须掌握的知识点

1. 词汇累计约 600–800（含课内）；会拼写核心词  
2. 一般现在时、现在进行时入门；be 动词、助动词 do/does  
3. 能读懂 50–80 词短文并回答问题  
4. 能写简单句（自我介绍、日记 3–5 句）

#### 掌握方法

- **听说：** 教材音频 + 英文动画/主题歌（看词跟唱可延续）每天 10–15 分钟  
- **读写：** 分级读物「听→跟读→指读→复述」；词句本加大 B 层听写比例  
- **拼写：** 自然拼读基础上听写核心词，按发音规律记，少死记字母顺序  
- **台账：** 继续用 [`英语词句积累学习方法.md`](英语词句积累学习方法.md) 跨学期跟踪

## 五、按学期拆开的步骤清单

### 二年级上（2026.9–2027.1）

1. 摸清校内进度与薄弱点（开学第一个月：口算限时、写字/错字本、英语跟读+词句本各测一次）  
2. 建立本子：**错字本**（见 [`语文错字积累与台账.md`](语文错字积累与台账.md)）、**错题本**、**阅读记录本**（见 [`阅读记录本使用方法.md`](阅读记录本使用方法.md)）、**英语词句本**  
3. 跑通作息：点心 → 作业 → 学习块 25～35 分钟 → 阅读 → 睡觉  
4. 语文：错字本销号 + 写话口述后写（每周 1 篇）；不恢复每天一页拼音  
5. 数学：乘法口诀上学期内过关；应用题 **秘籍专项每周 1～2 题**精做；计算限时减量  
6. 英语：校内沪教牛津跟紧；词句本 9 月认读、9 月底起小听写；牛津树/拼读重质量；HE 仅作听写工具  

逐周细节见 [`二上逐周计划表.md`](二上逐周计划表.md)。

### 二年级下（2027.2–2027.7）

1. 应用题专项：每周 3 题精做（画图+讲解）  
2. 写话从「通顺」升级到「有细节」（仍可口述后写）  
3. 桥梁书读通，暑假冲刺无拼音章节书  
4. 英语：词句本销号累计上升；教材外绘本分级精读少而精（约 10–20 本量）  

### 三年级上（2027.9–2028.1）

1. 习作专项：每两周 1 篇完整作文（家校结合）  
2. 多位数乘除过关；面积概念用实物理解  
3. 阅读理解开始「找依据」训练  
4. 评估是否需要英语外教/小班（以开口和兴趣为准；仍忌叠第四条视频线）  

### 三年级下（2028.2–2028.7）

1. 作文能独立写完并自我修改一稿  
2. 数学：分数初步扎实；暑假可预习四年级最基础部分（可选）  
3. 英语短文读写成型；词句本 L5 标准可加「能造句」  
4. **三年级结束总复盘：** 三科薄弱清单 → 定四年级是否加思维课/阅读课（仍忌全科狂补）

## 六、方法总表（全家共用）

| 原则 | 具体做法 |
|------|----------|
| 结构化收紧 | 三科各 1 条主线闭环；最小包 ≥70% 周数优先于加量 |
| 先课后拓 | 校内作业与单元卷必须先稳，再加课外 |
| 输出检验 | 会做 ≠ 会；要能讲给别人听、能限时做对 |
| 错题/错字/词句闭环 | 进本 → 复习 → 听写/重做 → 销号 |
| 阅读优先 | 语文提分与长远升学，阅读投入比刷题更划算 |
| 睡眠优先 | 小学生建议 9–10 小时睡眠；困了比再刷半小时更重要 |
| 二胎现实 | 质量>时长；爸爸妈妈轮流「陪伴讲解岗」，另一人带弟弟 |

## 七、与「深重点高中 / 211·985」的衔接说明（家长心里有数即可）

- **2–3 年级不决定高中**，但决定：学习习惯、阅读量、数学是否怕应用题、英语是否敢开口。  
- 深圳中考看：初中校额到校 + 中考分数 + 指标生等政策；眼前抓手是 **习惯与基础**，不是小学就「定校」。  
- 本阶段成功标准：喜欢看书、作业自驱、数学讲理、英语不抗拒、**三本本子会销号** → 四年级再叠加难度与选择性竞赛/拓展。
